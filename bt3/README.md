# CRUD Node.js với Express, Sequelize, MySQL (TypeScript)

## Cài đặt

```bash
yarn install
```

## Cấu hình env

Sửa file `.env` với thông tin MySQL của bạn:

```env
DB_HOST=localhost
DB_PORT=3306
DB_USERNAME=root
DB_PASSWORD=
DB_DATABASE=user
DB_DIALECT=mysql
DB_LOGGING=
```

## Build và chạy ứng dụng

```bash
yarn dev
```

## Truy cập ứng dụng

Mở trình duyệt tại [http://localhost:3000](http://localhost:3000)
